🔬 Methodology

📥 Data Collection

Integrated three comprehensive UN DESA Population Division datasets covering urban agglomeration, population estimates, and geographic locations.

🔧 Data Preprocessing

Advanced data cleaning, feature selection, and standardization using StandardScaler for optimal clustering performance.

🧠 Clustering Analysis

K-Means algorithm with k=3 clusters, evaluated using Silhouette Score and Davies-Bouldin Index for quality assessment.

📊 Visualization

PCA dimensionality reduction, interactive geographic mapping, and comprehensive feature analysis for actionable insights.
